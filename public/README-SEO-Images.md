# Images SEO requises pour Joaillerie Tournis

## Images OpenGraph nécessaires

### 1. Image principale OpenGraph

- **Fichier :** `public/img/og-image.jpg`
- **URL de production :** `https://tournis.netlify.app/img/og-image.jpg`
- **Dimensions :** 1200 x 630 pixels
- **Format :** JPEG
- **Contenu suggéré :** Logo Joaillerie Tournis + texte "Bijoux sur mesure depuis 1896" + image de bijoux
- **Taille max :** 8 MB

### 2. Images Twitter Card (optionnel)

- **Fichier :** `public/img/twitter-image.jpg`
- **Dimensions :** 1200 x 600 pixels
- **Format :** JPEG

### 3. Favicon complet (déjà présent)

- ✅ `public/favicon-16x16.png`
- ✅ `public/favicon-32x32.png`

## Instructions de création

### Pour l'image OpenGraph (og-image.jpg) :

1. Utilisez votre logo principal
2. Ajoutez le texte "Joaillerie Tournis - Bijoux sur mesure depuis 1896"
3. Incluez une image de vos plus beaux bijoux
4. Utilisez vos couleurs de marque (#1E2846)
5. Assurez-vous que le texte soit lisible même en petit

### Outils recommandés :

- Canva (templates OpenGraph disponibles)
- Adobe Photoshop/Illustrator
- Figma (gratuit)
- [OG Image Generator](https://og-image.vercel.app/)

## Test des métadonnées

Une fois l'image créée, testez avec :
